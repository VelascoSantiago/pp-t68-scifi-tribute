# T68 Sci-FI Tribute

**T68 Sci-Fi Tribute** is a 3D graphical and conceptual experience blending Mexico's historical memory with mecha design. Conceived as an alternate-history reimagining of the October 2, 1968 massacre, the project features a colossal mechanical guardian—designed with protest aesthetics and pre-Hispanic iconography—that embodies the resistance and victory of students against state oppression. The project integrates hard-surface modeling from Blender into an interactive, real-time rendered environment.
